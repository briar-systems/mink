# the Mach-O constants of the SDK headers, one table per enumeration.
#
# gen-tables.py reads this file and writes src/lib/macho/tables.mach. the values
# are the headers' own, at the revisions src/lib/macho.mach names.
#
# `table NAME HEADER` opens a table whose rows all come from HEADER. a row is
# `NAME VALUE`, VALUE in hex as the header declares it, a negative value written
# as its 64 bit two's complement. `text NAME HEADER` opens a table of string
# constants, whose rows are `NAME "text"`. `exclude NAME REASON` names a constant
# the tables leave out, and why.
