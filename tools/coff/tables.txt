# the PE/COFF constant tables, transcribed from the Microsoft PE Format specification.
#
# source of the spec rows: MicrosoftDocs/win32 desktop-src/Debug/pe-format.md at
# commit 8a9c5d8f3200 (2026-07-16), the text of the PE Format page. the names are the
# specification's own. a row the specification gives no value for takes the value
# from Wine's include/winnt.h (or include/winuser.h for resource types) at commit
# d38598c894f6, and says so in its source.
#
# the display column is the spelling llvm-readobj 23 prints for the row, and `=` is
# the name itself. where llvm-readobj spells a name by its word forms, the display is
# that form and its source is llvm-readobj's output, which the readobj lane checks.
#
# format:
#   table <TABLE> <description> opens a table
#   <TABLE> <NAME> <value> <display> <source>
#       defines a row. the value is decimal or 0x hex, a leading minus marks a signed
#       value, and the source runs to the end of the line
#   <TABLE> <NAME>
#       admits a row an earlier table defines, under the same value. a name is defined
#       once, and every table that includes it points at that one row
#   bytes <NAME> <hex> <source>
#       a byte string, outside any table
#   words <NAME> <TABLE>:<ROW> [<TABLE>:<ROW> ...] <source>
#       a byte string of the named rows' values, each as a little-endian 16-bit word,
#       which is the magic a file starts with. each is a magic of the registration
#   magics <TABLE>
#       a magic per distinct nonzero value of the table's rows, each the value as a
#       little-endian 16-bit word, for a file that starts with its machine word
#
# gen-tables.py turns this file into tables.mach.
